# Naplň Gym

Centrální rozcestník projektu webu společnosti **Naplň Gym**.

## Složky

- `web/dist/` – čistý výsledný web určený k nasazení na hosting.
- `web/README.md` – krátké pokyny k doplnění konfigurace a nasazení.
- `projekt/` – strategie, obsah, struktura, designová pravidla, technické zadání a záznam rozhodnutí.

## Aktuální fáze

Kompletní V1 je v implementaci podle schváleného briefu.

## Dohodnutý postup

1. Vyplnit vstupní dotazník.
2. Z odpovědí vytvořit stručné zadání a vyjasnit případné rozpory.
3. Schválit strategii a hlavní akci webu.
4. Schválit obsah a pořadí sekcí.
5. Schválit pravidla design systému a chování prvků.
6. Schválit technické řešení a podmínky spuštění.
7. Teprve poté postavit první plně použitelnou verzi webu.
