# Podklady od zadavatele

Sem patří kopie materiálů určených pro projekt, například:

- logo a jeho varianty;
- fotografie a videa;
- nabídka, ceník a prezentace;
- reference a případové studie;
- existující texty;
- právní texty;
- ukázky vizuálního stylu.

U každého neveřejného nebo licencovaného podkladu uveďte omezení použití. Hesla, přístupové údaje a jiné tajné údaje sem neukládejte.
